# SeniorTechSafe — Senior Care Technology Affiliate Site

Affiliate review site targeting US families (ages 40–55) researching
safety technology for aging parents.

🔗 Live site: [seniortechsafe.com](https://seniortechsafe.com)

## Features
- Product reviews & comparisons (medical alert systems)
- Expert scoring system (9.4/10 rating cards)
- Exit intent popups & contact modals
- Blog with SEO-optimized articles
- FTC compliant · CCPA & GDPR compliant
- Built on Blogger with custom HTML/CSS

## Tech used
HTML · CSS · Blogger · Affiliate Marketing · SEO · Canva

## Niche
Senior care · Medical alert systems · Fall detection ·
GPS tracking · USA audience
